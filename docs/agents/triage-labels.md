# Triage labels

The five canonical triage roles map 1:1 to label strings in this repo.
All labels exist on `jmpijll/discomfy`.

| Skill role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | `needs-info` | Waiting on reporter for more info |
| `ready-for-agent` | `ready-for-agent` | AFK-ready, fully specified |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

## v3-specific labels

These extend the canonical set; do not delete them when triaging.

| Label | Meaning |
| --- | --- |
| `v3.0` | Belongs to the v3.0 redesign milestone |
| `slice` | Vertical-slice tracer-bullet issue |
| `hitl` | Human-in-the-loop required (incompatible with `ready-for-agent`) |
| `enhancement` | New feature (default for slices) |
